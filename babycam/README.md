# 👶 집 와이파이 전용 베이비캠 (Windows + USB 웹캠)

Windows PC에 웹캠을 꽂고, 같은 와이파이에 연결된 폰 브라우저에서 **영상과 소리**를 실시간으로 봅니다.
인터넷(외부)에는 열리지 않고, 영상은 PC에서 폰으로 직접 전송됩니다 (WebRTC, 지연 1초 미만).

## 기능
- 실시간 영상 + 소리 (여러 대의 폰에서 동시에 볼 수 있음)
- **소리 알림**: 아기 소리가 일정 시간 이상 들리면 화면이 빨갛게 깜빡이고, 진동(안드로이드)과 알림음이 울림
- **연결 끊김 알림**: 카메라 연결이 20초 이상 끊기면 알림
- 야간 보정(밝기 올림), 화면 뒤집기, 전체화면
- 비밀번호 보호, PC 절전 모드 방지
- 카메라 PC를 껐다 켜도 폰이 자동으로 다시 연결

## 설치 (처음 한 번)
1. **파이썬 설치**: https://www.python.org/downloads/ → 설치 화면에서 **"Add python.exe to PATH" 체크**
2. 이 `babycam` 폴더를 PC의 원하는 위치에 복사
3. 웹캠을 USB에 연결

## 실행
1. `start.bat` 더블클릭
   - 처음 실행할 때 **Windows 방화벽** 창이 뜨면 **"개인 네트워크" 허용**을 누르세요.
   - 브라우저(Chrome/Edge)에 카메라 페이지가 열립니다. 카메라/마이크 권한을 **허용**하세요.
2. 검은 서버 창에 표시된 주소(예: `http://192.168.0.23:8000`)를 **폰 브라우저**에서 엽니다.
   - 사용자 이름은 아무거나, 비밀번호는 서버 창에 표시된 6자리 숫자
3. 폰에서 **"탭해서 보기"** → 영상과 소리가 나옵니다.
4. 브라우저 메뉴에서 **"홈 화면에 추가"**를 해 두면 다음부터는 앱처럼 열 수 있습니다.

> 카메라 페이지 탭과 검은 서버 창은 켜 둔 채로 두세요. 창을 최소화해도 되고 모니터가 꺼져도 됩니다.

## 꼭 설정해 둘 것
- **PC 와이파이를 "개인 네트워크"로**: 설정 → 네트워크 및 인터넷 → Wi-Fi → 연결된 와이파이 → "개인 네트워크". 공용으로 되어 있으면 폰에서 접속이 안 됩니다.
- **PC IP 주소 고정**: 공유기 관리 페이지에서 "DHCP 고정 할당(IP 예약)"으로 PC IP를 고정하면 폰 주소가 바뀌지 않습니다.
- **폰 화면 자동 잠금**: 보는 동안에는 화면이 꺼지지 않게 해 두세요. 특히 아이폰은 화면이 꺼지면 소리와 알림이 멈춥니다. 충전기를 꽂아 두고 자동 잠금을 "안 함"으로 하는 걸 권합니다.
- (선택) **윈도우 시작 시 자동 실행**: `Win+R` → `shell:startup` → 열린 폴더에 `start.bat`의 바로 가기를 넣기

## 설정 바꾸기
- **비밀번호**: `password.txt` 파일을 메모장으로 열어 바꾸고 `start.bat`을 다시 실행
- **화질/카메라/마이크**: 카메라 PC 페이지의 선택 상자에서 바꾸고 "다시 시작"
- **소리 알림 민감도**: 폰 화면의 슬라이더 (오른쪽으로 갈수록 작은 소리에도 알림). 흰 선이 기준이고, 막대가 이 선을 1.5초 이상 넘으면 알림이 울립니다.

## 문제 해결
| 증상 | 확인할 것 |
|---|---|
| 폰에서 주소가 안 열림 | 같은 와이파이인지(5GHz/2.4GHz 게스트망 주의), 방화벽 허용, 네트워크가 "개인"인지 |
| "카메라/마이크를 열 수 없습니다" | Zoom/카메라 앱 등 다른 프로그램이 웹캠을 쓰고 있지 않은지 |
| 계속 "카메라에 연결 중…" | PC의 카메라 페이지가 열려 있고 "방송 중"인지 확인 |
| 밤에 화면이 까맘 | 일반 웹캠은 어둠에서 안 보입니다. **적외선(IR) 나이트비전 웹캠**이 필요해요 |

## 구조
- `server.py`: 파이썬 표준 라이브러리만 쓰는 작은 서버 (페이지 제공 + 연결 정보 중계 + 비밀번호 확인)
- `static/cam.html`: 웹캠 PC에서 여는 페이지 (`http://localhost:8000/cam`, PC 본인만 열 수 있음)
- `static/view.html`: 폰에서 보는 페이지
